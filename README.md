# Memoria (módulo completo)

Hub standalone con los 4 minijuegos del módulo Memoria.

## Cómo ejecutarlo
Desde esta carpeta:

```bash
npm install
npm run dev
```

## Juegos
- Pares (`src/Memorama.tsx`)
- Secuencia / Retención / Ubicación (`src/MemoriaGames.tsx`)
- Hub (`src/App.tsx`)
- Estilos (`src/styles.css`)

## Cómo devolver cambios a la app
1. Edita y prueba aquí.
2. Reintegra en `src/components/MemoriaPanel.tsx` y/o `src/components/Memorama.tsx` (+ CSS en `src/index.css`).

Los stubs no van a la app.
